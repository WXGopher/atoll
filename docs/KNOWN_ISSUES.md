# 已知问题与维护事项

功能规划见 [路线图](ROADMAP.md)。本页保留实现限制和维护项，便于区分新功能与缺陷修复。

| 编号 | 项目 | 当前限制 |
| --- | --- | --- |
| M01 | 右键菜单深色模式 | 原生菜单未跟随 Atoll 的深色外观 |
| M02 | 本地管道访问权限 | 尚未显式绑定仅当前用户可访问的 DACL |
| M03 | 文档截图 | README 截图仍需覆盖新的悬停预览和设置项 |
| M04 | 日志时间 | 调试日志仍使用 UTC |
| M05 | 终端隐藏标签页定位 | 通过 `atoll-codex.exe` 启动的 Windows Terminal 会话已有精确身份定位；普通命令启动的旧会话仍依赖标题匹配 |
| M06 | 运行中分屏定位 | Atoll 启动的会话不依赖助手消息；关闭分屏、拖到其他窗口或重建控件导致身份失效时回退窗口或 Codex 桌面。IDE 不在本轮支持范围 |
| M07 | Codex hooks 信任状态 | 安装状态表示配置已写入；是否获准执行需在 Codex 的 `/hooks` 中确认 |
| M08 | 多种 Codex hooks 配置并存 | Atoll 保留已有内联 hooks 并将自己的条目写入 `hooks.json`；Codex 合并执行，可能提示同层存在两种表示 |
| M09 | Codex 原生提问接入 | 仅适用于 `atoll-codex.exe` 启动/恢复的 CLI 会话；app-server 与 WebSocket 为上游实验性接口。桌面端及普通 CLI 会话仍在 Codex 中作答；原生协议暂无多选 |
| M10 | Claude Code 验证 | 本机无法实际验证，整体标为实验性，新配置默认关闭 Claude 显示 |
| M11 | Codex 桌面存储兼容 | 分页历史读取为实验性，已验证本机 桌面应用 26.903.8094.0（后端 0.153.4）及 CLI 0.154.0 的存储结构；每轮最多检查最近 256 个主会话。不兼容时回退日志，暂时读取失败保留最多 30 秒；没有写入锁的旧客户端沿用十五分钟活动期限 |
| M12 | Codex 桌面原生回复 | 尚无已验证的公开附接通道；可观测的阻塞提问显示等待并跳回 Codex 作答，异步提问不误判为阻塞。Atoll 不向桌面数据库写入答案 |

旧路线图中的刷新参数已经过时：点击详情不会触发额度请求；Claude 额度缓存为 60 秒，缺少凭据时等待 600 秒再尝试。参数本身不作为功能里程碑。

Codex 额度按各会话最后一条有效额度事件的时间选择，每 30 秒在后台刷新；Windows 未更新日志文件修改时间或会话暂时没有活动时，额度仍会更新。数据以 Codex 已写入本地日志的记录为准。
