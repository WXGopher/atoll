## 中文

本次更新改善详情面板的排版，并让代理显示跟随实际活动。

- 修复重置日期和时间被截断的问题：重置时间独立成行，增加时钟图标，拉宽进度条并统一百分比对齐。
- 详情面板会根据重置时间行和会话数量调整高度，避免数据刷新后内容被底部裁切。
- 收到新 Hook 时检查代理活动，隐藏连续十五分钟没有活动的代理；再次调用时自动显示。Codex 通过新的本地日志事件触发相同逻辑。
- 启动时恢复上次保存的代理显隐、额度和会话文本，直到新活动到来才更新；旧日志和额度缓存不会自行让隐藏的代理重新出现。
- 启动和点击详情不再主动请求额度。Claude 额度仅由 Claude 活动触发刷新，减少闲置时的请求。
- 完善中文在前、英文在后的双语 README，并增加显示恢复和代理显隐的回归测试。

下载 `atoll-v0.1.4-windows-x86_64.zip`，解压后运行 `atoll.exe`。使用 Claude Code hooks 或已有稳定安装目录时，可运行 `atoll.exe setup install claude` 更新安装的程序和 hooks。压缩包附带 SHA-256 校验文件及 GitHub 构建来源证明。

## English

This update improves the details layout and makes agent visibility follow actual activity.

- Fix truncated reset dates and times with a dedicated reset line, a clock icon, wider progress bars and aligned percentages.
- Resize the details panel when reset lines or session counts change, keeping refreshed content inside the window.
- Check activity on each new hook and hide agents silent for fifteen minutes; new activity brings them back. New Codex log events trigger the same behaviour.
- Restore saved agent visibility, quota and session text at startup, then wait for new activity before updating. Old logs and cached quota do not independently restore hidden agents.
- Stop requesting quota at startup or when opening details. Claude activity triggers Claude quota refreshes, reducing idle requests.
- Update the bilingual README with Chinese first and English second, and add display restoration and visibility regression coverage.

Download `atoll-v0.1.4-windows-x86_64.zip`, extract it and run `atoll.exe`. For Claude Code hooks or an existing stable installation, run `atoll.exe setup install claude` to update the installed binaries and hooks. The release provides a separate SHA-256 checksum file and GitHub build provenance attestation.
