## 中文

本次更新修复任务栏显示和会话识别问题，并完善详情面板的使用体验。

- 修复任务栏控件偶发浅色块、原生标题栏和关闭按钮的问题，防止窗口样式在更新后被重新写回。
- 修复控件隐藏后再显示时丢失窗口句柄的问题，以及移动、尺寸和颜色更新时的重绘问题。
- 修复 Codex 正在工作时显示没有会话的问题，自动跟踪开始、完成、中断和恢复的会话。
- 详情面板在点击桌面、其他窗口或切换窗口后自动收起；再次点击 Atoll 图标仍可切换开关。
- README 改为完整中英双语，中文在前、英文在后。

下载 `atoll-v0.1.3-windows-x86_64.zip`，解压后运行 `atoll.exe`。需要 Claude Code 审批集成时运行 `atoll.exe setup install claude`。

## English

This update fixes taskbar rendering and session detection, and improves the details panel.

- Fix intermittent light blocks, native title bars and close buttons in the taskbar readout by preserving its frameless styles across backend updates.
- Fix lost window handles after hiding and showing the readout, and redraw issues during position, size and colour changes.
- Detect working Codex sessions automatically and follow turn starts, completions, interruptions and resumed conversations.
- Dismiss details after an outside click or a window switch, while keeping the Atoll icon's toggle behaviour.
- Provide a complete bilingual README with Chinese first and English second.

Download `atoll-v0.1.3-windows-x86_64.zip`, extract it and run `atoll.exe`. For Claude Code approvals, run `atoll.exe setup install claude`.
