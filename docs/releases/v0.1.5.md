## 中文

本次更新聚焦 Codex 会话跟踪、提问与跳转，并修复任务栏额度滞后。

- 修复 weekly 已剩余 75% 而 Atoll 仍显示 79% 的问题：按额度事件时间选择最新记录，每 30 秒后台刷新，不依赖 Windows 文件修改时间或新会话活动。
- 新增 Codex 桌面对话直达，以及 Windows Terminal 标签页、分屏精确定位。
- 通过 `atoll-codex.exe` 启动的 CLI 支持原生多题回复、选项说明、多行文本、秘密输入和返回修改；终端与卡片先答者生效。该接入为实验性。
- 补充桌面生命周期跟踪：只读分页历史、识别无 rollout 日志的会话、归档、中断、失败及断连。当前写入锁可保留长时间无输出的任务；失败和断连不会发送成功通知。分页历史适配为实验性。
- 新增待处理会话悬停预览、Codex 工具审批与静音完成通知；完成通知三秒后收起。
- Claude Code 明确标为实验性，新配置默认关闭；F04–F06 和 IDE 跳转不纳入本版。

**接入边界：**现有 Codex 桌面会话的原生问题仍需在 Codex 中回答。Atoll 可显示日志中可观测的阻塞提问并跳回对应会话，但没有向桌面直接写入答案的通道。F09 的桌面双向操作继续待接入，不列为已完成能力。

下载 `atoll-v0.1.5-windows-x86_64.zip`，解压后运行 `atoll.exe setup install codex` 更新本机安装，再启动安装目录中的 `atoll.exe`。压缩包包含 `atoll.exe`、`atoll-hook.exe`、`atoll-codex.exe`、README 和许可证；校验文件为 `SHA256SUMS.txt`。

## English

This release improves Codex session tracking, questions and navigation, and fixes stale taskbar quota.

- Choose the newest quota event across session logs and refresh locally every 30 seconds, even while idle or when Windows leaves file modification times unchanged.
- Open exact Codex desktop conversations and return to captured Windows Terminal tabs and panes.
- Answer native CLI questions through `atoll-codex.exe`, with multiple pages, option descriptions, multiline text, secret input and editable drafts. The first answer from the terminal or Atoll wins. This integration is experimental.
- Read desktop paginated history without modifying threads. Track sessions without rollout logs, archives, interruptions, failures and disconnects. Live writer locks retain quiet long-running work; failures and disconnects do not send success notifications. Storage compatibility is experimental.
- Add waiting-session hover previews, Codex approval cards and silent completion notifications that disappear after three seconds.
- Mark Claude Code experimental and hide it by default in new configurations. Additional agents, sounds, language switching and IDE navigation are outside this release.

**Boundary:** native questions in existing desktop sessions must still be answered in Codex. Observable blocking questions can be shown with a link back to their conversation. Direct desktop answers remain the unfinished portion of F09.

Extract `atoll-v0.1.5-windows-x86_64.zip`, run `atoll.exe setup install codex`, then start the installed `atoll.exe`. The archive contains all three executables, README and LICENSE. Use `SHA256SUMS.txt` to verify the archive.
