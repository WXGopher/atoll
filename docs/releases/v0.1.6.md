## 中文

本次更新新增 Codex CLI 状态栏定制，并修复普通 CLI 会话跳转到桌面 App 的问题。

- 在 **Settings → Codex TUI → Customize status bar** 打开编辑器。提供 30 个组件，勾选即时更新终端预览；常用的模型、目录、Git 分支、上下文、额度和任务进度排在前面。
- **Apply** 保存到 Codex 用户配置的 `tui.status_line`；全部取消后可隐藏状态栏。打开窗口和勾选只修改草稿，不写配置。
- **Restore Codex defaults** 一键移除自定义状态栏配置，由 Codex 使用自身默认值。主题和其他 TUI 设置保持原样。
- 保存前备份，保留其他设置、注释、现有组件顺序和未知组件；检测到外部修改时提示重新载入。支持 Tab、空格操作及高 DPI 缩放。
- 普通 CLI 的 `codex.exe` 不再被误认作桌面 App。跳转时寻找原终端；终端无法定位时保留详情面板。

**生效方式：**保存或恢复默认后，请重启 Codex CLI；可用 `codex resume` 继续原会话。项目、profile 或命令行覆盖配置可能优先于用户配置。组件和默认预览按 Codex CLI **0.154.0** 核对；预览使用示例数据，实际终端会省略无数据的组件。

验证包括 324 项通过的测试、格式检查、Clippy，以及 100%／150%／200% 缩放下的编辑器渲染和点击、键盘操作。

下载 `atoll-v0.1.6-windows-x86_64.zip`，退出正在运行的 Atoll，解压后运行 `atoll.exe setup install codex` 更新本机安装，再启动安装目录中的 `atoll.exe`。压缩包包含三个可执行文件、README 和许可证；使用 `SHA256SUMS.txt` 校验下载文件。

## English

This release adds a Codex CLI status-bar editor and fixes ordinary CLI sessions opening the desktop app when navigating back to them.

- Open **Settings → Codex TUI → Customize status bar** to toggle 30 components in a live terminal preview. Common model, directory, Git, context, quota and task-progress choices appear first.
- **Apply** saves `tui.status_line` in the Codex user configuration. An empty selection hides the footer. Opening the editor and toggling components only change the draft.
- **Restore Codex defaults** removes the custom footer override so Codex supplies its own defaults. Themes and other TUI settings remain intact.
- Back up configuration before writing; preserve unrelated settings, comments, existing order and unknown components. Detect external footer edits and request a reload. Support keyboard navigation and high-DPI scaling.
- Distinguish CLI `codex.exe` processes from the desktop app. Return to the original terminal when available, keeping the details panel open when the terminal cannot be located.

**Loading changes:** restart Codex CLI after applying or restoring defaults; use `codex resume` to continue a session. Project, profile and command-line overrides may take precedence. The catalog and default preview were checked against Codex CLI **0.154.0**. Preview values are illustrative; Codex omits unavailable data.

Validation includes 324 passing tests, formatting, Clippy, and editor rendering, clicks and keyboard interaction at 100%, 150% and 200% scale.

Download and extract `atoll-v0.1.6-windows-x86_64.zip`, quit Atoll, run `atoll.exe setup install codex`, then start the installed `atoll.exe`. The archive contains all three executables, README and LICENSE. Verify it with `SHA256SUMS.txt`.
